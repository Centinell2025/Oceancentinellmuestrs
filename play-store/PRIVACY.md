# OceanCentinell Business privacy policy

Effective November 24, 2026. Publisher: Beacon of the Eagle LLC. Contact: centinellsuite@gmail.com.

This free enterprise demonstration includes fictional maritime records. It stores demonstration incidents, maintenance statuses and a pilot draft in the Android app's local WebView storage or the current browser. No application server receives these local records. This version has no analytics, advertising SDK, customer account system or AI connection.

The optional AIS layer uses Internet access to request public regional vessel observations from the OceanCentinell gateway hosted on Railway. The gateway connects to AISStream using a server-side API key. Requests may expose network metadata, including IP address and request time, to Railway and the gateway. Incident records, task data and pilot drafts are not sent. The app does not request location, contacts, camera, microphone or broad storage permissions. Exports use Android's document picker and go to the location selected by the user. A cloud document provider selected by the user processes exported files under its own terms. A contact link can open the user's email application; sending an email is the user's action.

Local records and exports are not separately encrypted by this application. Do not enter confidential customer data. Clearing browser/app storage or uninstalling removes local records. Exported files remain wherever the user saved them and must be removed there. Android application backup/device-transfer exclusions are configured. Browser storage behavior depends on the browser.

No app account is created, so no server account deletion is necessary. Use device/browser settings to clear the complete local workspace. CSV and JSON exports are available in the Privacy & local data section. Validated demonstration JSON backups can be restored locally after the user confirms replacement of the current records.

The demonstration is intended for adults evaluating maritime operations workflows and is not designed for children. For privacy or support requests, contact centinellsuite@gmail.com.
